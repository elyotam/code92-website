Code92 היא סוכנות דיגיטלית לעסקים שרוצים לצמוח, עם מיקוד בארבעה תחומי ליבה:

- **פיתוח אתרים** — אתרי חנות, אתרי תדמית ודפי נחיתה, ברמת עיצוב גבוהה ובנויים להמרה
- **אפליקציות וחנויות E-commerce** — פתרונות דיגיטליים מותאמים אישית לצרכי העסק
- **אוטומציות AI** — סוכני AI ומערכות חכמות שחוסכות זמן עבודה ידני ומייעלות מכירות ושירות
- **תשתיות ענן ואבטחה** — ליווי שוטף מאסטרטגיה ועד השקה, ואחריה

**אתר חי:** [elyotam.github.io/code92-website](https://elyotam.github.io/code92-website/)

## טכנולוגיה

אתר Vanilla — HTML5, CSS3 ו-JavaScript (ES6+), ללא framework או תהליך build. תמיכה מלאה בדו-לשוניות (עברית/אנגלית), וצ'אט מונחה-AI המחובר ל-Cloudflare Workers לשאלות פתוחות.

## יצירת קשר

דרך טופס יצירת הקשר באתר, או כפתור ה-WhatsApp הזמין בכל עמוד.
