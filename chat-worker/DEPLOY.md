# פריסת ה-AI Worker (חד-פעמי, ~5 דקות)

זה השרת הקטן שמחזיק את ה-AI (Cloudflare Workers AI) ועונה על שאלות פתוחות בצ'אט. אין בו שום מפתח API להזין — Cloudflare מריצה את המודל בעצמה. חשבון Cloudflare חינמי, בלי כרטיס אשראי, מספיק.

## שלבים

1. פתחו טרמינל בתוך התיקייה `chat-worker/`:
   ```
   cd chat-worker
   ```

2. התחברות לחשבון Cloudflare (ייפתח דפדפן להתחברות/הרשמה):
   ```
   npx wrangler login
   ```

3. פריסה:
   ```
   npx wrangler deploy
   ```

4. בסיום, wrangler ידפיס כתובת כמו:
   ```
   https://code92-chat-ai.<your-subdomain>.workers.dev
   ```
   העתיקו את הכתובת המדויקת הזו.

5. פתחו את `main.js` בתיקיית האתר (לא בתיקיית `chat-worker`), חפשו את השורה:
   ```js
   const AI_WORKER_URL = 'https://code92-chat-ai.YOUR-SUBDOMAIN.workers.dev';
   ```
   והחליפו את `YOUR-SUBDOMAIN.workers.dev` בכתובת האמיתית שקיבלתם בשלב 4.

זהו — הצ'אט יתחיל לענות על שאלות פתוחות עם AI אמיתי. עד שהשלב הזה לא בוצע, הצ'אט ממשיך לעבוד כרגיל (השיחה המונחית), פשוט בלי היכולת לענות על שאלות חופשיות.

## עלות

10,000 Neurons ביום בחינם (בלי כרטיס אשראי) — מספיק בנוחות לכמות שיחות טיפוסית לאתר עסק קטן, כי ה-AI מופעל רק עבור שאלות פתוחות אמיתיות, לא על כל הודעה בשיחה. אם אי פעם תעברו את המכסה היומית, Cloudflare תבקש להוסיף אמצעי תשלום כדי להמשיך מעבר לחינמי (עלות זעומה, כ-1 סנט לכל 1,000 Neurons נוספים) — עד אז שום דבר לא נחסם.

## עדכון הקוד בעתיד

אחרי כל שינוי ב-`worker.js`, פשוט הריצו שוב `npx wrangler deploy` מתוך `chat-worker/` — הכתובת נשארת זהה.
